# Code of conduct

My projects follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By taking part in issues, pull requests, discussions, or any other project space, you agree to follow it.

## Report a problem

If you experience or see behavior that breaks the code of conduct, tell me privately through the [contact form on courtneyr.dev](https://courtneyr.dev/contact/). Don't report it in a public issue.

I'll read every report and keep the reporter's identity private.

## Enforcement

I enforce the code of conduct using the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): a correction, then a warning, then a temporary ban, then a permanent ban, depending on how serious the behavior is and whether it repeats.
