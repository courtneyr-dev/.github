# Getting help

Start with the project's README and documentation site. Most of my plugins link their docs from the repository's **About** section.

## Where to ask

- **A bug:** open an issue with the **Bug report** form.
- **A feature idea:** open an issue with the **Feature request** form.
- **A question about a plugin listed on WordPress.org:** ask in that plugin's support forum on WordPress.org, so other users can find the answer.
- **IndieWeb concepts** such as Webmentions, microformats, or POSSE: the [IndieWeb wiki](https://indieweb.org/) and [IndieWeb chat](https://chat.indieweb.org/) are the best places to learn and ask.
- **A security vulnerability:** follow [SECURITY.md](SECURITY.md). Don't use a public issue.

## Response times

I maintain these projects in my own time and reply to issues as time allows. Security reports get an acknowledgement within 48 hours.
